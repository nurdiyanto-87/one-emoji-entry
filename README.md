One emoji that stands for Tanduran, an AI agent that finds the way through work: a compass. Tanduran is Javanese for planting and growing — an agent that plants, tends and grows work (research, tasks, bounties) — and the compass is the instrument of that work: it decides direction and navigates a bare request to a finished result. It reads instantly at small size, says something specific about how the agent works, and stays far from the obvious robot or smiley.

## Run it

```sh
python3 main.py
```
